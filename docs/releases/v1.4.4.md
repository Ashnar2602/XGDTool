# XGDTool v1.4.4 — Desktop XEX Folder-to-ISO Conversion (Windows & Linux CLI/GUI)

### What Changed & Why

* **Desktop GUI XEX Folder Selection (Single & Multi-Select) (`MainFrame.cpp`, `MainFrame_Create.cpp`)**:
  * **Change**: Added a dedicated **XEX Folder** (`Cartelle XEX`) button next to **Browse** on Windows and Linux GUI builds, supporting single game folders and batch multi-selection via a checklist dialog when selecting a parent directory containing multiple extracted games (up to 2 levels deep).
  * **Why**: Previously, selecting extracted XEX/XBE game folders on desktop required manually choosing directories one by one with no batch checklist or automatic format switch; if `Extract` was selected, adding an XEX folder now switches the output format to `XISO` automatically and labels entries as `XEX/DIR`.

* **Desktop CLI `--iso` Flag & Directory Path Handling (`main.cpp`, `InputHelper.cpp`, `InputHelper_FS.cpp`)**:
  * **Change**: Added `--iso` as an alias for `--xiso`, normalized trailing directory slashes (`\` and `/`), added direct `.xex` file parent-folder resolution, added 2-level nested XEX folder discovery, and redirected output automatically if the output folder is inside the source XEX directory.
  * **Why**: Trailing slashes from shell tab-completion caused `std::filesystem::path::filename()` to return an empty string (producing unnamed `.iso` outputs), passing `default.xex` directly triggered a directory-iterator error, and writing an ISO inside the source XEX folder risked self-inclusion in the AVL tree.

* **Localization & Embedded Resources (`languages/*.xml`, `EmbeddedLanguages.h`)**:
  * Updated all 6 desktop languages (EN, IT, DE, ES, FR, PT) and regenerated embedded language resources for standalone executables.
