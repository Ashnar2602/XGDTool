# XGDTool v1.4.2 — Android XEX Folder Selection & Directory Conversion

### What Changed & Why

* **Android XEX/XBE Folder Selection (Single & Multi-Select) (`activity_main.xml`, `MainActivity.kt`)**:
  * **Change**: Added a dedicated **XEX Folders** (`Cartelle XEX`) button in the Source panel below **Choose ISO/XISO**, with support for both single game folder selection and multi-folder batch selection via a Material 3 checklist dialog.
  * **Why**: Standard Android file pickers (`OpenMultipleDocuments`) only select individual files and navigate into directories instead of selecting them. Adding a dedicated directory tree selector allows converting extracted XEX/XBE game folders (or entire parent directories containing multiple extracted games) into `ISO`, `ZAR`, `GOD`, `CCI`, or `CSO`.

* **Zero-Copy & SAF Directory Conversion Pipeline (`ConvertService.kt`, `PathUtils.kt`)**:
  * Extended `PathUtils.resolveDocumentFile()` to resolve `file://`, SAF Document, and SAF Tree URIs for directories in Zero-Copy mode, added nested game root resolution (`resolveGameDirectory`), and added recursive SAF folder caching when running without All Files Access.

* **Core C++ Executable & Extension Discovery (`TitleHelper.cpp`, `InputHelper_FS.cpp`)**:
  * `TitleHelper::initialize()` now falls back to any `.xex` or `.xbe` executable in the directory if `default.xex` / `default.xbe` is absent, and `InputHelper::has_extension()` matches exact file extensions via `path.extension()`.
